# IIIT Internship — IV Drip Anomaly Detection

Research internship at iHub-Data, IIIT Hyderabad (March–May 2026, Dr. C. K. Raju).

## What I did

- Built a custom IV drip anomaly detection dataset from video frames: extracted frames with FFmpeg and annotated them in Label Studio in YOLO format.
- Fine-tuned YOLOv8n on that dataset for IV drip anomaly detection.

## Results

- **99.5% mAP@50**
- **87.9% mAP@50-95**

## Tools

Python, YOLOv8, Label Studio, FFmpeg
